ECEN403 Subsystem 1: BENIGN-ONLY baseline evaluation
All captures are assumed benign according to supplied dataset labels.
Baseline files were READ, not retrained or modified.
Only chronological held-out windows were scored for rate calculations.
Rates are candidate window-level threshold-exceedance fractions of known-benign data.
Comparing 2/3/4/5 multipliers on this held-out set is exploratory; if selecting
a threshold using these results, evaluate it again on NEW independent benign data.
Not a real-time attack detector; no detection sensitivity/attack recall established.
3-window episodes count distinct consecutive held-out flagged windows offline,
not Prometheus 'for' time and not validated threat/response events.
A source's 'any-feature' threshold rate is not an attack false-alarm rate.
An unscorable zero-variance feature is not a passed test.
Lower bounds clamped to zero for these nonnegative traffic metrics.
